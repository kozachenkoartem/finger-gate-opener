# Finger Gate Opener

Проект устройства для открытия калитки по отпечатку пальца. В репозитории
хранится 3D-модель корпуса для датчика R558S.

## Датчик отпечатка пальца R558S

R558S — круглый оптический датчик отпечатка пальца со встроенной обработкой
шаблонов. Он получает изображение пальца, формирует и сохраняет шаблоны, а
также выполняет поиск совпадений; управляющая плата взаимодействует с ним по
UART.

| Характеристика | Значение |
| --- | --- |
| Питание и уровни логики | 3.3 В |
| Интерфейс | UART, 57 600 бод |
| Ёмкость базы шаблонов | До 100 отпечатков |
| Размер лицевой части | Около 21–22 мм в диаметре |
| Индикация | Встроенная светодиодная подсветка |

Вход `RX` датчика не рассчитан на 5 В. При подключении к плате с логикой 5 В
нужен преобразователь уровней либо резистивный делитель между `TX` платы и
`RX` датчика. Линии UART подключаются перекрёстно: `TX` датчика к `RX`
контроллера, `RX` датчика к `TX` контроллера.

Источник параметров: [R558S Arduino Library](https://github.com/nahomyirga787-spec/R558S).
Перед изготовлением устройства следует сверить параметры с документацией
конкретной ревизии приобретённого датчика.

## Корпус датчика

Каталог [`STL/`](STL/) содержит корпус, рассчитанный на установку R558S в
калитке или другой панели. Модель имеет скруглённый внешний контур, центральное
посадочное отверстие под датчик, внутреннюю выборку и полукруглый канал для
кабеля на задней стороне.

| Параметр модели | Значение |
| --- | --- |
| Внешние размеры | 32 × 32 × 14 мм |
| Скругление углов | Радиус 7 мм |
| Отверстие под датчик | Диаметр 19.1 мм |
| Внутренняя выборка | Диаметр 23 мм |
| Толщина передней стенки | 2 мм |
| Кабельный канал | Диаметр 3 мм |
