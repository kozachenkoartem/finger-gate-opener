# Finger Gate Opener

Проект устройства для открытия калитки по отпечатку пальца. В репозитории
хранится 3D-модель корпуса для датчика R558S.

## Прошивка ESP32-C3 SuperMini

Каталог [`firmware/`](firmware/) содержит минимальную прошивку ESP-IDF для
первой проверки платы. Она не использует Arduino Framework, Wi-Fi, реле или
операции с базой отпечатков R558S.

При запуске `app_main()` выводит в последовательный лог модель и ревизию
чипа, версию ESP-IDF, причину последней перезагрузки и объём свободной кучи.
Затем проверяет обмен с R558S: в обычном состоянии включает красную
подсветку, а при касании переводит её в зелёную на одну секунду. Все команды
проверяют ответ датчика. Встроенный синий светодиод на GPIO8 продолжает мигать
с интервалом одна секунда.

### Подготовка ESP-IDF

Нужен ESP-IDF 5.x. Ниже пример установки ESP-IDF 5.5.3 в домашний каталог на
Linux:

```sh
mkdir -p ~/esp
git clone --recursive --branch v5.5.3 https://github.com/espressif/esp-idf.git ~/esp/esp-idf-v5.5.3
~/esp/esp-idf-v5.5.3/install.sh esp32c3
```

Перед каждой сборкой откройте новую оболочку и активируйте окружение:

```sh
. ~/esp/esp-idf-v5.5.3/export.sh
```

### Сборка и прошивка

Подключите ESP32-C3 SuperMini к USB-кабелю передачи данных. Определите
последовательный порт, например `ls /dev/ttyACM* /dev/ttyUSB*`; ниже он указан
как `<PORT>`.

```sh
idf.py -C firmware set-target esp32c3
idf.py -C firmware build
idf.py -C firmware -p <PORT> flash
idf.py -C firmware -p <PORT> monitor
```

Чтобы выйти из монитора, нажмите `Ctrl-]`. Ожидаемый результат: строки
диагностики платы и мигание встроенного синего светодиода. Если светодиод не
реагирует, уточните его GPIO для конкретной ревизии платы перед изменением `kLedGpio` в
[`firmware/main/main.cpp`](firmware/main/main.cpp).

### HTTPS-администрирование

После подключения к Wi-Fi откройте `https://finger-gate-XXXX.local/` либо
`https://<IP-платы>/`. Начальные credentials — `admin` / `admin`, с обязательной
заменой пароля. Сертификат устройства самоподписанный. Настройка, API и результаты
проверки описаны в [`docs/https-admin.md`](docs/https-admin.md).

## Датчик отпечатка пальца R558S

R558S — ёмкостный модуль распознавания отпечатков пальцев со встроенной
обработкой и хранением шаблонов. Модуль самостоятельно регистрирует отпечатки
и выполняет поиск совпадений; управляющая плата обменивается командами и
результатами по UART.

| Характеристика | Значение |
| --- | --- |
| Питание и уровни логики | 3.3 В |
| Интерфейс | UART, 57 600 бод |
| Ёмкость базы шаблонов | До 100 отпечатков |
| Диаметр части, проходящей через панель | Около 19 мм (посадочное отверстие в напечатанном корпусе — 19,1 мм) |
| Наружный диаметр буртика | 21 мм (измерено на имеющемся экземпляре) |
| Индикация | Встроенная светодиодная подсветка |

Вход `RX` датчика не рассчитан на 5 В. При подключении к плате с логикой 5 В
нужен преобразователь уровней либо резистивный делитель между `TX` платы и
`RX` датчика. Линии UART подключаются перекрёстно: `TX` датчика к `RX`
контроллера, `RX` датчика к `TX` контроллера.

Ориентир по протоколу и электрическим характеристикам: [руководство R558-S (PDF)](https://cdn-shop.adafruit.com/product-files/4750/R558-S_fingerprint_module_user_manual-V1.1_1___2___1_.pdf).
Перед подключением необходимо сверить распиновку и допустимые напряжения с
документацией конкретной ревизии датчика; цвета проводов сами по себе не
гарантируют правильного подключения.

Для проверки касания подключите модуль при отключённом питании:

| R558S | ESP32-C3 SuperMini |
| --- | --- |
| VCC | 3.3 V |
| GND | GND |
| TX | GPIO4 (RX) |
| RX | GPIO5 (TX) |
| TOUCH_OUT | GPIO3 (вход без внутренней подтяжки) |

Тестовая версия пока не выполняет регистрацию, поиск, удаление или запись
шаблонов. До фактического подключения датчика достаточно выполнить
`idf.py -C firmware build`; прошивайте плату только после проверки проводов.

Проверенный формат протокола и результаты стендовой регистрации описаны в
[`docs/r558s-protocol.md`](docs/r558s-protocol.md).

## Корпус датчика

Каталог [`STL/`](STL/) содержит корпус, рассчитанный на установку R558S в
калитке или другой панели. Модель имеет скруглённый внешний контур, центральное
посадочное отверстие под датчик, внутреннюю выборку и полукруглый канал для
кабеля на задней стороне.

| Параметр модели | Значение |
| --- | --- |
| Внешние размеры | 32 × 32 × 14 мм |
| Скругление углов | Радиус 7 мм |
| Отверстие под датчик | Диаметр 19.1 мм |
| Внутренняя выборка | Диаметр 23 мм |
| Толщина передней стенки | 2 мм |
| Кабельный канал | Полукруглый, радиус 1,5 мм, углублён на 0,8 мм относительно предыдущей версии |
